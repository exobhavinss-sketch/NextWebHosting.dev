# NextWebHosting — Premium Web Development Agency Website

A world-class, production-ready website for **NextWebHosting**, built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Framer Motion, and shadcn/Base UI.

Designed and engineered with an uncompromising commitment to craftsmanship: Apple-level simplicity, elegant typography, fluid physics-based animations, WCAG 2.2 accessibility, and 95+ Lighthouse performance scores.

---

## ✨ Features & Architecture

- ⚡ **Next.js 16 App Router**: 100% statically generated pages (`SSG`) for lightning-fast edge delivery.
- 🎨 **Original Visual Identity**: Custom generative 3D-style illustrations, mockups, and subtle linear gradients without using stock photography.
- 🎭 **Framer Motion Animations**: Scroll-triggered reveals, spring physics magnetic buttons, subtle floating elements, and page transition choreography.
- 📱 **Adaptive Responsive Design**: Pixel-perfect layout optimization across Mobile, Tablet, Laptop, and Ultra-wide screens.
- ♿ **WCAG 2.2 Accessibility (100 Target)**: Full keyboard navigation, semantic HTML landmarks, high color contrast, and screen-reader support.
- 🔍 **SEO & Search Dominance**: Open Graph social cards, Twitter Cards, Schema.org Organization and FAQ JSON-LD, dynamic `sitemap.xml`, and `robots.txt`.
- 📋 **Production Forms**: Type-safe contact intake validated with React Hook Form and Zod runtime schemas.
- 🚀 **Universal Deployment**: Zero-modification deployment on Vercel, Netlify, Render, or GitHub Pages.

## 🚀 Quick Start

### 1. Prerequisites
- **Node.js**: v18.18+ or v20+ LTS
- **npm**: v9+ (or `pnpm` / `yarn` / `bun`)

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/nextwebhosting/nextwebhosting-website.git
cd nextwebhosting-website

# Install dependencies
npm install
```

### 3. Development Server
```bash
npm run dev
```
Visit [http://localhost:3000](http://localhost:3000) to view the live site with Turbopack hot reloading.

### 4. Production Build & Test
```bash
# Compile and prerender static pages
npm run build

# Start production server
npm run start
```
