## 2. Core Web Vitals Optimizations

### Largest Contentful Paint (LCP < 1.2s)
- **Priority Image Preloading**: The hero section image uses `priority` on Next.js `<Image>`, generating `<link rel="preload">` in the document `<head>`.
- **Preconnected Fonts**: Google Fonts (`next/font/google`) automatically self-hosts the font files at build time, eliminating external render-blocking font requests.
- **Server Component Rendering**: The initial HTML payload is rendered on the server, avoiding client-side rendering delays.

### Cumulative Layout Shift (CLS < 0.02)
- **Explicit Aspect Ratios**: All `<Image>` elements use either predefined `width`/`height` or fill containers with fixed CSS aspect ratios (`aspect-[16/10]`, `aspect-[4/3]`).
- **Font Display**: Utilizes `display: "swap"` with zero-shift fallback metric overrides generated by Next.js font tools.
- **Reserved Layout Slots**: Dynamic elements maintain explicit heights to avoid layout jumps during mount.

### Interaction to Next Paint (INP < 100ms)
- **Hardware-Accelerated Animations**: Framer Motion transforms exclusively target GPU-composited properties (`transform`, `opacity`, `translate3d`).
- **Passive Event Handlers**: Window scroll listeners use passive observers via `framer-motion`'s `useScroll` engine.
- **De-duped Re-renders**: State updates in forms and filters are isolated to localized island components.

---

## 3. Asset & Code Optimization

- **CSS Tree Shaking**: Tailwind CSS v4 only outputs CSS for classes actually present in the source files, resulting in minimal CSS payload.
- **Next.js Turbopack Builds**: Rapid static rendering generates pre-compressed HTML files with zero hydration delays for content sections.
- **Modern Web Formats**: Original custom illustrations are loaded with responsive `sizes` attributes for optimal viewport delivery.
